# Work Order Tracker

A small Node.js application built to practice JavaScript and application development concepts.

## Features

- Create work orders
- Search work orders by ID
- Update work order status
- Delete work orders
- Prevent duplicate work-order IDs
- Store data using JSON
- Save changes between application runs

## Technologies

- JavaScript
- Node.js
- JSON
- Visual Studio Code

## Concepts Practiced

- Functions
- Arrays
- Objects
- CRUD operations
- File handling
- JSON parsing
- Data persistence
